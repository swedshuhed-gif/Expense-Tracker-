## 📖 Описание программы

**Expense Tracker** — графическое приложение для учёта личных расходов. Разработано на Python с использованием библиотеки Tkinter. Позволяет добавлять расходы, фильтровать по категориям и датам, подсчитывать сумму за выбранный период и сохранять данные в JSON формате.

### Основные возможности:
- ✅ Добавление расхода (сумма, категория, дата, описание)
- ✅ Подсчёт суммы расходов за выбранный период
- ✅ Фильтрация по категории
- ✅ Фильтрация по дате (с... по...)
- ✅ Сохранение и загрузка данных через JSON
- ✅ Валидация ввода (сумма > 0, корректный формат даты)
- ✅ Удаление записей
